## 1. What Is Needed

- The landing needs C_{resp,∞}(1+β₀)/L ≤ (1−β)/4 (note #5.3, #5.7). This is a fixed fraction of L, so any bound C(d)(1 + log L)^qL^{1−η} with η = η(d) > 0 suffices for L large given d. The one-scale passage gives C(d) (#5.10.5), and (i) may lose up to L^{1−η}.
- LFR I (1.64) and (1.66) (p.190 l.21–48) bound abs(A′) on the fine bonds of each layer m. So (i) needs a sup bound on ∂ω on fine bonds at the interfaces, not only on the layers' own averages.

## 2. Reduction to Two Layers at Scale j (Derived)

- PRT2 (2.101)–(2.110) (p.241–242): at the interface Λ_j/Λ_{j+1}, the gauge on the layers ≥ j is λ = H′_jμ, with μ on the scale-j lattice (scale-j units below).
  - On the layer-j side F, μ is the datum itself, because Q′ there is the scale-j average.
  - On the coarse side C, only the means of μ over the L-blocks (the scale-(j+1) blocks) are fixed.
  - The quadratic form is ⟨μ, Aμ⟩ with A := Δ′_j = H′_j*Δ²H′_j ((2.107)), normalised as a = n^{d−4}a₀ below.
- *The factor M.* In scale-j units A = M*M with M := n^{2−d/2}ΔH′_j, which maps functions on the scale-j lattice to fine functions (Δ the fine Laplacian). By #5.10.2.1 (a ≤ 3), abs(M(x, y)) ≤ C(d)n^{−d/2}e^{−δ abs(x/n − y)}, with C(d) and δ(d) free of n = L^j and L.
  - M annihilates the affine functions p of y: p = Q′_jπ for an affine fine π, and H′_jQ′_jπ = π (#5.10.2 (b)), so Mp = n^{2−d/2}Δπ = 0.
  - *Lemma M.* For every g on the scale-j lattice and every fine x in the block y_x, abs(Mg(x)) ≤ C(d)n^{−d/2}Σ_ze^{−δ abs(z − y_x)/2}abs(∇²g(z)), with ∇² the second differences of the scale-j lattice. *Proof:* Mg(x) = Σ_yM(x, y)R(y), with R(y) := g(y) − g(y_x) − ∇g(y_x)·(y − y_x) the Taylor remainder, since M kills the affine part. Along a monotone lattice path from y_x to y, each first difference differs from ∇g(y_x) by a sum of second differences in the box spanned by y_x and y, enlarged by one site, so abs(R(y)) ≤ d·abs(y − y_x)Σ_{z∈box}abs(∇²g(z)). A site z lies in that box only if abs(y − y_x) ≥ abs(z − y_x) − √d. Also abs(x/n − y) ≥ abs(y − y_x) − √d, and Σ_{abs(y−y_x)≥s}abs(y − y_x)e^{−δ abs(y − y_x)} ≤ C(d)e^{−δs/2}. So the coefficient of abs(∇²g(z)) is ≤ C(d)n^{−d/2}e^{−δ abs(z − y_x)/2}. ∎
  - The symbol of A is analytic and 2π-periodic on a strip of width δ(d) (#5.10.2.1: there Δ(θ)²S₂(θ) ≥ ½(2/π)^{2d}), and c₁Δ₀(q)² ≤ â(q) ≤ c₂Δ₀(q)² at real q, with c₁, c₂ of d only. PRT2 (2.109) (p.242) prints this bound with no stated dependence of its constants, which follows from #5.10.2.1 as follows.
    - On the cell, â(q) = (n²Δ(q/n))²g(q) up to the normalisation, with g := 1/(Δ(θ)²S₂(θ)) at θ = q/n. #5.10.2.1 gives (2/π)^{2d} ≤ Δ(θ)²S₂(θ) ≤ 1 + C(d) at real q, the k ≠ 0 terms being summable.
    - n²Δ(q/n) = Σ_μq_μ²k(q_μ/n) and Δ₀(q) = Σ_μq_μ²k(q_μ), with k(t) := 2(1 − cos t)/t² ∈ [4/π², 1] for abs(t) ≤ π. So π²/4 ≥ n²Δ(q/n)/Δ₀(q) ≥ 4/π², and c₁, c₂ depend on d only. A is not factored through Δ₀: for n > 1, â/Δ₀² is not analytic at q = 0, and its kernel decays only polynomially.
- The L-dependence of PRT2's coercivity (2.110) comes from the L-block constraint on C. It enters below only through Poincaré on the L-blocks, with weights in L-units.
- The other interfaces are at distance ≥ RML^jη (PRT II (2.2)), that is, RM/L L-blocks. PRT2 itself localises to cubes in which only two scales meet ((2.89)–(2.93), p.239 l.2–38). The far layers are removed as follows, with R and M chosen after L, M ≥ L, and RM ≥ L².
  - *Lemma A′ (fine lattice, all layers).* Work with the fine field: the least ‖Eh − Δf‖ (or ‖∂*A_N + Δf‖) over f with the layered constraints, n_B the side of the constraint block B (L^{j′} on the layer j′). Let ñ be a scale function with n_B ≤ ñ on B, abs(∇ñ) ≤ ε(d), and ñ ≤ L·n_B. It rises from L^{j′} to L^{j′+1} inside the layer j′, over the width L^{j′+1}/ε next to its interface with the layer j′ + 1, which fits since the layer's width is ≥ RML^{j′}. Let w := e^{κρ} with abs(∇ρ) ≤ 1/ñ and abs(∇²ρ) ≤ C/ñ². Then ‖wΔc‖ ≤ C(d)‖w(ΔE − Eh)‖ for κ, ε ≤ κ₀(d), with c := f − E and E a field with the given block means, as in §4.
  - *Proof:* §4's four steps with ñ for L and Δ² for A, that is, with M := Δ, for which Lemma M is the pointwise bound abs(Δg) ≤ C(d)abs(∇²g).
    - (1) Block Poincaré uses n_B: ‖ñ^{−2}wc‖_B ≤ C(d)ñ^{−2}n_B‖w∇c‖_B ≤ C(d)‖ñ^{−1}w∇c‖_B. In the summation by parts, abs(∇(ñ^{−2}w²)) ≤ C(d)(ε + κ)ñ^{−3}w², which is absorbed. So ‖ñ^{−1}w∇c‖ + ‖ñ^{−2}wc‖ ≤ C(d)‖wΔc‖.
    - (2) w varies by a factor ≤ 1 + C(d)κn_B/ñ on B, so abs(m_B) ≤ C(d)κ(n_B/ñ)w_B²n_B^{d/2}‖c‖_B, and with ‖c‖_B ≤ C(d)n_B‖∇c‖_B, ‖w^{−1}Δt‖ ≤ C(d)κ‖ñ^{−1}w∇c‖ ≤ C(d)κ‖wΔc‖.
    - (3)–(4) as in §4, with abs(∇w²) ≤ C(d)κñ^{−1}w² and abs(Δw²) ≤ C(d)κñ^{−2}w². ∎
  - *Distances.* PRT2 (2.2) (p.224 l.10–12) gives dist(Ω_{j′}ᶜ, Ω_{j′+1}) > RML^{j′} in fine units, so the layer j′ has width > RML^{j′}. On the layer j, ñ ≤ L^{j+1}, and on the layer j + 1, ñ ≤ L^{j+2}. So the ρ-distance from the interface between them to the other interfaces is ≥ RM/L, and the coupling is ≤ C(d)e^{−κRM/L}.
  - The condition ω = 0 on Λ₀ is the case of zero data on the unit blocks of Λ₀ (n_B = 1), and is covered by the same constraints.
  - *Comparison with the two-layer problem.* Let U be the ρ-ball of radius RM/(3L) about a point z of the interface. It lies in the layers j and j + 1, so it is a union of blocks of both problems. Let f₁ (all layers) and f₂ (the layers j and j + 1 only, continued outward) be the minimisers with the same data and the same h. Test functions supported in U with zero block means are admissible in both, so d := f₁ − f₂ has zero block means on U and satisfies ⟨Δd, Δφ⟩ = 0 for all of them. Also Δ²d = Q′_lay*(λ₁ − λ₂) on U, with λ_i the multipliers: the terms of h cancel.
    - *The data energy.* Let E_i be the bump field of problem i's data, with abs(∇E_i) ≤ C(d)𝒜 and abs(ΔE_i), abs(Eh) ≤ C(d)𝒜/n_B (#5.10.4, §3's sizes), and 𝓔 := max_i(‖w′(ΔE_i − Eh)‖ + ‖w′ñ^{−1}∇E_i‖), with w′ := e^{−κρ(·, U)} (ρ smoothed at the scale ñ here and below, so that abs(∇²ρ) ≤ C(d)/ñ²). The ρ-volumes are not used; the count is of fine sites.
      - On the layer j′ the summand is ≤ C(d)𝒜²L^{−2j′}, since n_B = L^{j′} there. ñ ≤ L^{j′+1} on the layer j′, so a fine path of length ℓ through the layers ≤ m has ρ-length ≥ ℓL^{−m−1}. U has fine radius ≤ (RM/(3L))L^{j+2} about z.
      - A ρ-geodesic from U to a site x may pass through layers coarser than x's, where its fine length grows faster. So the ball is taken by the coarsest layer m(x) ≥ max(j′, j + 1) that a ρ-geodesic from U to x visits: x lies within the fine distance C(d)(r + 1 + RM)L^{m(x)+1} of z, so there are at most the d-th power of that many such x. For m(x) ≥ j + 2 that geodesic crosses the layers j + 1, …, m(x) − 1, so r ≥ (m(x) − j − 1)·2RM/(3L) − 1. Summing over m := m(x) multiplies each bound below by Σ_{m≥j+1}L^{d(m−j−1)}e^{−2κ(m−j−1)RM/(3L)} ≤ 2, by the condition e^{−2κRM/(3L)}L^{2d} ≤ ½ below, which uses half of the exponent e^{−4κ(·)RM/(3L)}.
      - The layers j and j + 1 give ≤ C(d, κ)(RM)^dL^{d(j+2)}L^{−2j}𝒜², since Σ_r(r + 1 + RM)^de^{−2κr} ≤ C(d, κ)(RM)^d.
      - The layer j + 1 has ρ-width ≥ RM/L from the interface through z, and each layer has ρ-width ≥ RM/L. So the layer j′ ≥ j + 2 lies at the ρ-distance ≥ (j′ − j − 1)·2RM/(3L) from U. It gives at most (C(d)(j′ − j))^dL^{(d−2)(j′−j−1)}e^{−4κ(j′−j−1)RM/(3L)} times the layers j and j + 1.
      - Likewise the layer j′ < j lies at the ρ-distance ≥ (j − j′)·2RM/(3L) from U. Its sites lie in the same ball as those of the layer j, and its summand is L^{2(j−j′)} times larger. It gives at most (C(d)(j − j′))^dL^{2(j−j′)}e^{−4κ(j−j′)RM/(3L)} times the layers j and j + 1.
      - Since e^{−2κRM/(3L)}L^{2d} ≤ e^{−2κL/3}L^{2d} ≤ ½ for L ≥ L₀(d, κ) (RM ≥ L²), both series converge, and 𝓔 ≤ C(d, κ)L^{c(d)}(RM)^{d/2}n^{d/2−1}𝒜 with c(d) := d + 1.
      - On a far layer Λ₀ (n_B = 1, when j ≥ 1) the bump bound is pointwise, and 𝒜 there is replaced by sup W·‖A_N‖_W ≤ (1 + log L)^pL‖A_N‖_W. The extra factor (1 + log L)^pL is absorbed by the final e^{−κRM/(7L)} below, since RM/L ≥ L.
    - *Local energies.* By Lemma A′ with the weight w′, and its step (1), ‖Δf_i‖_U + ‖ñ^{−1}∇f_i‖_U ≤ C(d)𝓔.
    - *Decay into U.* Let η be a cutoff equal to 1 on U except its outer ρ-layer of width 1, and w := e^{κρ(·, ∂U)}, which grows into U. The proof of Lemma A′ with c := ηd and φ := w²ηd − t, where the commutator terms of η live on the outer layer, on which w ≤ e^{κ} and ‖ñ^{−2}d‖ ≤ C(d)‖ñ^{−1}∇d‖ by the zero block means, gives ‖wΔd‖_{U′} + ‖ñ^{−1}w∇d‖_{U′} ≤ C(d)(‖Δd‖ + ‖ñ^{−1}∇d‖)_U ≤ C(d)𝓔, with U′ the part on which η = 1.
    - *Lemma R (block-scale sup bound).* Let n ≤ n′ ≤ Ln and c(d) := 8 + √d. Let f on B_{c(d)n′}(b) satisfy Δ²f = g, with g constant on each constraint block in that ball, whose sides lie in [n, n′]. Then abs(∇f(b)) ≤ C(d)[n′^{−d/2}‖∇f‖_{B_{2n′}(b)} + L³n^{1−d/2}‖Δf‖_{B_{c(d)n′}(b)}].
      - (1) For each such block B, of side n_B, a bump ψ_B in B with Σψ_B = 1 and ‖Δψ_B‖ ≤ C(d)n_B^{−2−d/2} gives g_B = ⟨Δ²f, ψ_B⟩ = ⟨Δf, Δψ_B⟩. So abs(g) ≤ C(d)n^{−2−d/2}‖Δf‖_{B_{c(d)n′}} on B_{8n′}.
      - (2) The harmonic measure of a cube C_{2r} from its centre is ≤ c(d)r^{1−d} (Lawler–Limic p.131, the proof of Theorem 6.3.8, from Lemma 6.3.7). C_{2r} has half-side 2r, so it lies in B_{2√d·r}(x) ⊂ B_{n′}(x) for r ≤ n′/(2√d). By Jensen, and averaging over r ∈ [n′/(4√d), n′/(2√d)], a function h harmonic in B_{2n′}(x) obeys h(x)² ≤ C(d)n′^{−d}‖h‖²_{B_{2n′}(x)} (the mean value bound).
      - (3) v := Δf satisfies Δv = g on B_{8n′}. With G the Green function of ℤ^d, normalised so that Δ(G*φ) = φ, and v_p := G*(1_{B_{8n′}}g), abs(v_p) ≤ C(d)n′²sup abs(g) (Lawler–Limic Theorem 4.3.1, p.81–82), and v − v_p is harmonic in B_{8n′}. By (2) at the points of B_{4n′}, and (1), sup_{B_{4n′}}abs(Δf) ≤ C(d)(n′^{−d/2} + n′²n^{−2−d/2})‖Δf‖_{B_{c(d)n′}} ≤ C(d)L²n^{−d/2}‖Δf‖_{B_{c(d)n′}}.
      - (4) F := G*(1_{B_{4n′}}Δf) has abs(∇F) ≤ C(d)n′sup_{B_{4n′}}abs(Δf) (Lawler–Limic Corollary 4.3.3, p.84), and each ∇_μ(f − F) is harmonic in B_{4n′}. By (2), abs(∇(f − F)(b)) ≤ C(d)(n′^{−d/2}‖∇f‖_{B_{2n′}} + sup_{B_{2n′}}abs(∇F)). With (3) and n′ ≤ Ln, the claim follows. ∎
    - *Sup bounds.* Take n′ := Ln if b lies on the coarse side or within the fine distance 9n of the interface, and n′ := n otherwise. Then the constraint blocks in B_{c(d)n′}(b) have sides in [n, n′], as Lemma R asks: on the coarse side they have side Ln = n′. Then n′/C(d) ≤ ñ ≤ Ln′ on B_{c(d)n′}(b): ñ rises to L^{j+1} at the interface with abs(∇ñ) ≤ ε, and on the layer j + 1 it stays L^{j+1} within U, since its rise to L^{j+2} lies at the ρ-distance ≥ RM/L − C/ε from the interface. So that ball has ρ-radius ≤ C(d), and Lemma R applies to d, by Δ²d = Q′_lay*(λ₁ − λ₂). For b within the ρ-distance RM/(6L) of z, w ≥ e^{κRM/(6L) − C(d)} on that ball, and the decay into U gives ‖∇d‖_{B_{2n′}} ≤ C(d)Ln′e^{−κRM/(6L)}𝓔 and ‖Δd‖_{B_{c(d)n′}} ≤ C(d)e^{−κRM/(6L)}𝓔. Since n′ ≥ n, Lemma R then gives abs(∂d(b)) ≤ C(d)L³n^{1−d/2}e^{−κRM/(6L)}𝓔 ≤ C(d, κ)L^{c(d)+3}(RM)^{d/2}e^{−κRM/(6L)}𝒜, free of n. Since RM/L ≥ L, this is ≤ C(d, κ)e^{−κRM/(7L)}𝒜 for L ≥ L₀(d, κ).
  - So at z the fine-bond bounds of the layered problem are those of the two-layer problem at scale j, up to C(d)e^{−κRM/(7L)} times the data. The rest of this draft treats the two-layer problem.

## 3. The Kernel Requirement (Derived)

- For a fine bond b in the scale-j block y_b, H′_j reproduces constants. So by #5.10.2.1,
  abs(∂ω(b)) ≤ C(d)L^{−j}Σ_ye^{−δ abs(y − y_b)}abs(μ(y) − μ(y_b)) + (the τ-part).
- The data obey abs(μ(y)) ≤ C(d)n_y𝒜_y (#5.10.4), with n_y the side of y's block in its own layer.
- So it suffices that Σ_yabs(∂H′_lay(x, y))n_y ≤ C(d)(1 + log L)^qL^{1−η}, with H′_lay the layered H′. The sum splits into the coarse data (n_y = L^{j+1}) and the fine data on F (n_y = L^j).
- *The τ-part (derived, given §7 for its part (b)).* Write 𝒜 := sup_y avg_{B(y)}abs(A_N).
  - The Taylor route of #5.10.3 loses powers of L here: P_lay's range is L^{j+1} on C, and the Taylor remainders of τ_y grow over it. So T_lay is reduced to scale j and to local sources instead.
  - P_lay := H′_layQ′_lay is the Δ²-orthogonal projection onto the complement of N(Q′_lay). So (I − P_lay)τ is the Δ²-projection of τ onto N(Q′_lay), the least ‖Δ(τ − f)‖ = ‖Eh − Δf‖ over f ∈ N(Q′_lay).
  - *Splitting.* Every f ∈ N(Q′_lay) is f = ν + H′_jμ with ν ∈ N(Q′_j) and μ := Q′_jf ∈ S₀ (§4), since Q′_jH′_j = I. The parts are Δ-orthogonal: ⟨Δν, ΔH′_jμ⟩ = ⟨ν, Q′_j*Aμ⟩ = 0, from Δ²H′_j = Q′_j*A (PRT2 (2.102), (2.108)).
  - So ‖Eh − Δf‖² = ‖Eh − Δν‖² + a(μ, μ) − 2⟨Eh, ΔH′_jμ⟩, and the two minimisations separate: ν = (I − P_j)τ, the uniform τ-part at scale j, and μ = μ_τ ∈ S₀ with a(μ_τ, φ) = ⟨Eh, ΔH′_jφ⟩ for every φ ∈ S₀.
  - Hence T_layh = T_jh̃ + ∂H′_jμ_τ, with h̃ := h read on the scale-j blocks (Eh = E_jh̃). The source ⟨Eh, ΔH′_jφ⟩ = −⟨∂E_jh̃, ∂H′_jφ⟩ is local: no τ, and no growth at infinity. This is the exact form, as in #5.10.1 on PRT2's torus.
  - *Sizes.* The bump bound of #5.10.3 holds on every scale-j block, since ∂*A_N = Eh is constant on it: n abs(h̃_y) ≤ C(d)avg_{B(y)}abs(A_N). On C the bump at the scale of the L-blocks gives more, Ln abs(h_Y) ≤ C(d)avg_{B_L(Y)}abs(A_N) ≤ C(d)𝒜, an average over the L-block also at j = 0.
  - (a) T_jh̃ is the uniform τ-part at scale j, so abs(T_jh̃) ≤ C(d)𝒜 by #5.10.3.
  - ∂E_jh̃ lives on the fine bonds across the scale-j faces where h̃ jumps: on F every face, with jumps ≤ C(d)𝒜/n, and on C only the faces of the L-blocks, with jumps ≤ C(d)𝒜/(Ln). φ vanishes on F, and the kernel of H′_j decays at the rate δ(d)/n (#5.10.2.1). So the F-faces enter with the weight e^{−δ dist(·, C)} in scale-j units. In scale-j units, with a = n^{d−4}a₀, the source is s(φ) := Σ_{faces}σ·∇φ up to these tails, with abs(σ) ≤ C(d)n𝒜e^{−δ dist(·, C)} on F and abs(σ) ≤ C(d)n𝒜/L on the faces of the L-blocks in C.
  - (b) The F-part: summation by parts moves the difference onto σ, so it is a source of size C(d)n𝒜e^{−δ dist(·, F)} paired with φ on C. This is the class of the fine data in §7 (data of size C(d)n𝒜 on F, acting on C through A's tails), so its contribution to ∂H′_jμ_τ is ≤ C(d)(1 + log L)^qL^{1−α/2}𝒜. This holds for j ≥ 1, where the scale-j blocks of F have side ≥ L and 𝒜 is an average.
  - (b₀) *The face of Λ₀ (j = 0).* At j = 0 the blocks of F = Λ₀ are single sites, so h on F is ∂*A_N itself, and the bump bound gives no average.
    - The bonds of Λ₀ carry A_N = B, the fine datum, since ζ^N = 0 on Λ₀ (the large-field note's #0.1.4). So abs(h(x)) ≤ C(d)(θ_B + max_bW(b)‖A_N‖_W), the maximum over the bonds b from x into C.
    - φ vanishes on F, so h on F enters only through g(q) := Σ_{x∈F, x∼q}h(x) at the sites q ∈ C next to F. Its part of μ_τ is Σ_qG_S(·, q)g(q), with G_S of §7 and H′_0 = I.
    - Run §7's count for the unit differences in x with the data g in place of a constant, using three facts:
      - On the face sites at the distance ≍ D from x, avg W ≤ C(d)(1 + log L)^pL^κ(L/max(D, t₃(x)/2))^{1−κ}.       - The x-side exponent is 1 at the scales D ≤ s̄(x), and γ := α/2 above them. Here s̄ := max(s, ρ₀), with s the distance from x to the strata of ∂C of codimension ≥ 3 (Lemma D at x up to s̄, Lemma B at the stratum beyond).

So abs(s(w)) ≤ C(d)(n𝒜/L)r^{d/2}‖∇²w‖, the bound of a bulk source of size γ := n𝒜/L.
    - Lemma A holds with s in place of −a(E, ·), by the same proof, and gives the local energy ‖Δ₀μ_τ‖²_{B_L} ≤ C(d)γ²L^d = C(d)(Ln𝒜)² in d = 4.
    - Lemma B holds with such a source. In its step (2), abs(s(η⁴v)) ≤ ε‖η²Δ₀v‖² + C(d)γ²r^d + (terms already there), so Φ(r) ≤ θΦ(Kr) + C(d)γ²r^d. Iterating down from R = L/4, with K^dθ > 1, gives Φ(r) ≤ C(d)(r/L)^α[Φ(L/4) + γ²L^d] ≤ C(d)(r/L)^α(Ln𝒜)².
    - The multipliers follow from the bump test as in §6, with a source term ≤ C(d)(R/L)^{d+4}(Ln𝒜)².
    - The oscillation of §5 with R = L/4, M = C(d)L^{−α}(Ln𝒜)², and g_R ≤ C(d)L^{−d/2}·L‖Δ₀μ_τ‖_{B_L} ≤ C(d)n𝒜 (Lemma A (1)), gives abs(∇μ_τ) ≤ C(d)(log L)²L^{1−α/2}n𝒜.
    - So the contribution of (c) to ∂H′_jμ_τ is ≤ C(d)(log L)²L^{1−α/2}𝒜.
  - Altogether, abs(T_layh) ≤ C(d)(1 + log L)^qL^{1−α/2}𝒜: the bound of §1, given §7.

## 4. Lemma A: Localisation at the Scale of the L-Blocks (Derived)

**Setting.** S₀ := {c ∈ ℓ²(ℤ^d): c = 0 on F, Σ_{y∈B}c(y) = 0 for every L-block B ⊂ C}. Let a(c, c′) := ⟨c, Ac′⟩ = ⟨Mc, Mc′⟩ (§2), so c₁‖Δ₀c‖² ≤ a(c, c) ≤ c₂‖Δ₀c‖² ((2.109)), with c₁ and c₂ depending on d only. Let E be any field with E = μ on F and the given L-block means on C. The minimiser is μ = E + c, with c ∈ S₀ and a(c, φ) = −a(E, φ) for every φ ∈ S₀.

**Claim.** Let w := e^{κρ/L}, with ρ bounded, abs(∇ρ) ≤ 1, and abs(∇²ρ) ≤ C(d)/L. Then for κ ≤ κ₀(d), ‖wΔ₀c‖ ≤ C(d)‖w∇²E‖. The constants do not depend on sup ρ. So any 1-Lipschitz ρ, smoothed at the scale L and capped smoothly at a height T ≥ L, may be used, and T → ∞ by monotone convergence.

**Proof.**
- (1) *Weighted Poincaré.* Let κ ≤ 1. On an L-block B, w ≤ e^{2dκ}w_B, with w_B := w at B's centre. Block Poincaré for mean zero gives ‖c‖_B ≤ C(d)L‖∇c‖_B, so ‖wc‖ ≤ C(d)L‖w∇c‖, since c = 0 on F.
  Summing by parts on ℤ^d, ‖w∇c‖² = ⟨−Δ₀c, w²c⟩ − ⟨∇c, (∇w²)c⟩ ≤ ‖wΔ₀c‖‖wc‖ + C(d)(κ/L)‖w∇c‖‖wc‖.
  So for κ ≤ κ₀(d), ‖w∇c‖ ≤ C(d)L‖wΔ₀c‖ and ‖wc‖ ≤ C(d)L²‖wΔ₀c‖.
- (1′) *Second differences.* On ℤ^d, ‖∇²g‖ = ‖Δ₀g‖ for g ∈ ℓ², since Σ_{μ,ν}abs(e^{iq_μ} − 1)²abs(e^{iq_ν} − 1)² = Δ₀(q)². Take g := wc. For κ ≤ 1, abs(∇w) ≤ C(d)(κ/L)w and abs(∇²w) ≤ C(d)(κ/L²)w, so ∇²(wc) − w∇²c and Δ₀(wc) − wΔ₀c are ≤ C(d)w[(κ/L)abs(∇c) + (κ/L²)abs(c)] at neighbouring sites. By (1) their norms are ≤ C(d)κ‖wΔ₀c‖, so ‖w∇²c‖ ≤ C(d)‖wΔ₀c‖ and ‖Δ₀(wc)‖ ≥ (1 − C(d)κ)‖wΔ₀c‖.
- (2) *The test function.* Let ψ_B be a bump in B with Σψ_B = 1 and abs(∇^kψ_B) ≤ C(d)L^{−d−k}. Put t := Σ_Bm_Bψ_B with m_B := Σ_{y∈B}w²c(y). Then φ := w²c − t ∈ S₀.
  Since Σ_Bc = 0, m_B = Σ_B(w² − w_B²)c, so abs(m_B) ≤ C(d)κw_B²L^{d/2}‖c‖_B. Hence ‖w^{−1}∇²t‖ ≤ C(d)κL^{−2}‖wc‖ ≤ C(d)κ‖wΔ₀c‖.
- (3) *The commutators.* Let W(x) := w(y_x) at the fine site x, and let κ ≤ δ(d)/16.
  - By Lemma M, ‖WMg‖ ≤ C(d)‖w∇²g‖ and ‖W^{−1}Mg‖ ≤ C(d)‖w^{−1}∇²g‖: the weights at y_x and z differ by ≤ e^{κ abs(z − y_x)/L}, which e^{−δ abs(z − y_x)/2} absorbs, and in Schur's test the n^d fine sites of a block cancel the factor n^{−d}.
  - For v := w^s, s = 1, 2, [M, v]g(x) := M(vg)(x) − v(y_x)Mg(x) = M((v − v(y_x))g)(x). With abs(v(z) − v(y_x)) ≤ C(d)(κ/L)abs(z − y_x)e^{2κ abs(z − y_x)/L}v(z), abs(∇v) ≤ C(d)(κ/L)v, and abs(∇²v) ≤ C(d)(κ/L²)v, Lemma M gives W(x)^{1−s}abs([M, v]c(x)) ≤ C(d)n^{−d/2}Σ_ze^{−δ abs(z − y_x)/4}w(z)[(κ/L²)abs(c) + (κ/L)abs(∇c) + (κ/L)abs(∇²c)], the brackets taken at z and its neighbours. By Schur's test, (1), and (1′), ‖W^{1−s}[M, w^s]c‖ ≤ C(d)κ‖wΔ₀c‖.
  - So a(c, w²c) = ⟨Mc, M(w²c)⟩ = ‖WMc‖² + ⟨WMc, W^{−1}[M, w²]c⟩. Here ‖WMc‖ ≥ ‖M(wc)‖ − ‖[M, w]c‖ ≥ c₁^{1/2}‖Δ₀(wc)‖ − C(d)κ‖wΔ₀c‖ ≥ (c₁^{1/2} − C(d)κ)‖wΔ₀c‖, by (2.109) for wc ∈ ℓ² and (1′), and ‖WMc‖ ≤ C(d)‖w∇²c‖ ≤ C(d)‖wΔ₀c‖. Hence a(c, w²c) ≥ (c₁ − C(d)κ)‖wΔ₀c‖².
- (4) *Conclusion.* abs(a(c, t)) ≤ ‖WMc‖‖W^{−1}Mt‖ ≤ C(d)‖wΔ₀c‖‖w^{−1}∇²t‖ ≤ C(d)κ‖wΔ₀c‖², by (2). The right side is abs(a(E, w²c − t)) ≤ ‖WME‖‖W^{−1}M(w²c − t)‖ ≤ C(d)‖w∇²E‖‖wΔ₀c‖, since ‖w^{−1}∇²(w²c)‖ ≤ C(d)‖wΔ₀c‖ as in (1′). For κ ≤ κ₀(d) this gives the claim. ∎

**Consequences.**
- The response to data supported near a point q decays like e^{−κ abs(· − q)/L}, at an L-free rate.
- The local energy at the scale of the L-blocks is at most C(d) times ‖∇²E‖² for any local feasible field E.
- No step uses a weight that is constant on blocks. The block means are restored by t, at the cost Cκ.

## 5. Lemma B: Hölder Decay at the Fat Boundary (Derived)

**Claim.** Let u = 0 on F satisfy a(u, φ) = Σ_Bκ_B⟨1_B, φ⟩ for every φ supported in B_R(z) and vanishing on F, with R ≤ L/4. Let w := e^{κρ/L}, with ρ 1-Lipschitz and κ ≤ δ(d)/16, and E_w := w(z)^{−2}‖w∇²u‖² (w = 1 gives the total energy). Let S := max_{B∩B_R≠∅}abs(κ_B)². Then there are α = α(d) > 0 and C(d) such that, for C(d)log L ≤ r ≤ R,

  Φ(r) ≤ C(d)(r/R)^α[Φ(R) + R^{d+4}S + L^{−1}log L·E_w], with Φ(r) := ‖∇²u‖²_{B_r(z)}.

**Proof.**
- (1) *Fatness.* Let A_r := B_{Kr}(z)∖B_r(z), with K = K(d) fixed below. F is a union of cubes of side ≥ L ≥ 4r in scale-j units: the layers are unions of big blocks, the M-cubes of their scale (PRT2 (2.2), p.224 l.10), and M ≥ L, a choice of M after L (§2). If B_{2r}(z) meets F at p, the cube of F through p contains a cube of side 4r through p, which lies in B_{K(d)r}(z) for K(d) := 2 + 4√d. Its volume (4r)^d exceeds that of B_r(z) by ≥ c(d)r^d, since 4^d exceeds the volume of the unit ball. So F ∩ A_r and its interior (the sites whose neighbours all lie in F) have measure ≥ c(d)r^d for r ≥ C(d).
- (2) *Caccioppoli.* Let η be 1 on B_r, supported in B_{2r}, with abs(∇^kη) ≤ C(d)r^{−k}, and v := u − p.
  - Take p = 0 if B_{2r} meets F, and otherwise p the affine fit of u on A_r. Then a(p, ·) = 0, since Mp = 0 (§2), and φ := η⁴v vanishes on F, since η is supported in B_{2r}. Also ∇²v = ∇²u and Mv = Mu.
  - *The commutators.* With H(x) := η(y_x), M(η^sv) = H^sMu + [M, η^s]v for s = 2, 4, where [M, η^s]v(x) = M((η^s − η^s(y_x))v)(x). By Lemma M, abs([M, η^s]v(x)) ≤ C(d)n^{−d/2}Σ_ze^{−δ abs(z − y_x)/2}abs(∇²((η^s − η^s(y_x))v)(z)).
    - The terms with a difference of η live on B_{2r}∖B_r ⊂ A_r, and are ≤ C(d)(r^{−2}abs(v) + r^{−1}abs(∇v)) there.
    - The term (η^s(z) − η^s(y_x))∇²u(z) is ≤ C(d)min(1, abs(z − y_x)/r)abs(∇²u(z)), and it vanishes unless one of z, y_x lies in B_{2r} and one lies outside B_r. Its part with abs(z − y_x) ≤ r lies in B_{3r}. Its part with abs(z − y_x) > r carries e^{−δ abs(z − y_x)/2} ≤ e^{−δr/4}e^{−δ abs(z − y_x)/4}. There abs(∇²u(z)) = w(z)^{−1}·w(z)abs(∇²u(z)), with w(z)^{−1} ≤ w(z₀)^{−1}e^{κ(abs(z − y_x) + 2r)/L} and κ/L ≤ δ/16.
    - By Schur's test, ‖[M, η^s]v‖ ≤ C(d)𝒞, with 𝒞 := r^{−2}‖v‖_{A_r} + r^{−1}‖∇v‖_{A_r} + r^{−1}‖∇²u‖_{B_{3r}} + e^{−δr/8}E_w^{1/2}.
  - *The form.* a(v, η⁴v) = ⟨Mu, M(η⁴v)⟩ = ‖H²Mu‖² + ⟨Mu, [M, η⁴]v⟩. By (2.109) and (1′) of §4 with κ = 0, Φ(r) ≤ ‖∇²(η²v)‖² = ‖Δ₀(η²v)‖² ≤ c₁^{−1}‖M(η²v)‖² ≤ 2c₁^{−1}(‖H²Mu‖² + C(d)𝒞²). The pairing ⟨Mu, [M, η⁴]v⟩ is ≤ C(d)(‖∇²u‖_{B_{4r}} + e^{−δr/8}E_w^{1/2})𝒞, by Lemma M for Mu on the blocks within 4r of z and the decay of [M, η⁴]v off B_{3r}.
  - The sources give abs(Σκ_B⟨1_B, η⁴v⟩) ≤ S^{1/2}r^{d/2}‖v‖_{B_{2r}} ≤ C(d)S^{1/2}r^{d/2+2}‖∇²u‖_{B_{Kr}}, by Poincaré on B_{Kr}, as in (3).
  - With ab ≤ εa² + b²/(4ε), the parts of ε‖∇²u‖² and r^{−1}‖∇²u‖² on B_r are absorbed for ε ≤ ε(d) and r ≥ C(d), and their parts on B_{Kr}∖B_r ⊂ A_r remain. This gives
    Φ(r) ≤ C(d)[‖∇²u‖²_{A_r} + r^{−2}‖∇v‖²_{A_r} + r^{−4}‖v‖²_{A_r}] + C(d)e^{−δr/4}E_w + C(d)Sr^{d+4}.
- (2′) *The pure form (used in Lemma D).*
  - In (2), the terms in ‖∇²u‖² outside B_r come only from the pairing, through ε‖∇²u‖²_{B_{4r}}, and from the commutator, through r^{−2}‖∇²u‖²_{B_{3r}}.
  - Run (2) with η equal to 1 on B_ρ and supported in B_{ρ′}, r ≤ ρ < ρ′ ≤ 2r, with ρ′ − ρ ≥ C(d)log L in place of r in the bounds on η's differences. This gives Φ(ρ) ≤ θ₁Φ(ρ′ + C(d)) + C(d)[(ρ′ − ρ)^{−2}‖∇v‖²_{B_{3r}} + (ρ′ − ρ)^{−4}‖v‖²_{B_{3r}}] + (tails) + (sources), with θ₁ := ε + C(d)(ρ′ − ρ)^{−1} ≤ 2^{−5} for ε ≤ ε(d) and log L ≥ C(d).
  - Take ρ_i := r(2 − 2^{−i}) for i ≤ m, with 2^{−m}r ≍ C(d)log L, so the gaps r2^{−i−1} ≥ C(d)log L absorb the shift C(d). Summing θ₁^i times these inequalities, Σ_iθ₁^i2^{4i} ≤ 2, gives
    Φ(r) ≤ C(d)[r^{−2}‖∇v‖²_{B_{3r}} + r^{−4}‖v‖²_{B_{3r}}] + (C(d)log L/r)^5Φ(2r) + (tails) + (sources).
- (3) *Poincaré on the annulus.* About the affine fit, or with the fat zero sets of v and ∇v from (1): ‖∇v‖_{A_r} ≤ C(d)r‖∇²u‖_{A_r} and ‖v‖_{A_r} ≤ C(d)r²‖∇²u‖_{A_r}. So Φ(r) ≤ C₀(Φ(Kr) − Φ(r)) + (tails and sources), and Φ(r) ≤ θΦ(Kr) + …, with θ := C₀/(C₀ + 1) (Widman's hole-filling).
- (4) *Iteration.* Take C₀ ≥ 1, so θ ≥ ½ and θK^{d+4} > 1, and let r_i := RK^{−i} and α := log_K(1/θ). Then Φ(r_{i+1}) ≤ θΦ(r_i) + C(d)Sr_{i+1}^{d+4} + C(d)e^{−δr_{i+1}/4}E_w.
  - The sources sum to Σ_{i≤m}θ^{m−i}r_i^{d+4} = θ^mR^{d+4}Σ_{i≤m}(θK^{d+4})^{−i} ≤ C(d)θ^mR^{d+4}.
  - For r_i ≥ C(d)log L, e^{−δr_i/4} ≤ L^{−1−α} ≤ (r_i/R)^αL^{−1} = θ^iL^{−1}, so the tails sum to ≤ mθ^mL^{−1}E_w, with m ≤ log_K(R/r) ≤ C(d)log L.
  - Since θ^m ≤ C(d)(r/R)^α, the claim follows. ∎

**The oscillation (derived; d = 4).** Let ρ₀ := C(d)log L, and a ∈ (0, 2).
- Suppose Φ(B_s(z′)) ≤ Ms^a for every z′ ∈ B_{R/2}(z) and ρ₀ ≤ s ≤ R/2. Lemma B gives this at every such centre with a = α and M := C(d)R^{−α}𝓔, 𝓔 := Φ(B_R(z)) + R^{d+4}S + L^{−1}log L·E_w, since B_{R/2}(z′) ⊂ B_R(z). Let g_R := sup_{z′∈B_{R/2}(z)}abs((∇u)_{R/4,z′}), with (·)_{s,z′} the average over B_s(z′).
- *Gradient averages.* Poincaré on balls gives abs((∇u)_{s,z′} − (∇u)_{2s,z′}) ≤ C(d)s^{1−d/2}Φ(B_{2s}(z′))^{1/2} ≤ C(d)M^{1/2}s^{−1+a/2}. Summing over dyadic s up to R/4, abs((∇u)_{s,z′}) ≤ g_R + C(d, a)M^{1/2}s^{−1+a/2}, and so ‖∇u‖²_{B_s(z′)} ≤ C(d, a)(Ms^{2+a} + s⁴g_R²) for ρ₀ ≤ s ≤ R/4.
- *Gradient.* abs(∇u(z′)) ≤ ‖∇u‖_{B_{ρ₀}(z′)} ≤ C(d, a)(M^{1/2}ρ₀^{1+a/2} + ρ₀²g_R) for z′ ∈ B_{R/2}(z).
- *Oscillation.* abs(u_{s,z′} − u_{2s,z′}) ≤ C(d)s^{1−d/2}‖∇u‖_{B_{2s}(z′)} ≤ C(d, a)(M^{1/2}s^{a/2} + s·g_R), and abs(u(z″) − u_{ρ₀,z″}) ≤ C(d)ρ₀max_{B_{ρ₀}(z″)}abs(∇u) is bounded by the gradient bound. Comparing the averages over B_s(z″) ⊂ B_{2s}(z′), osc_{B_s(z′)}u ≤ C(d, a)ρ₀²(M^{1/2}s^{a/2} + s·g_R) for z′ ∈ B_{R/4}(z) and ρ₀ ≤ s ≤ R/8.
- *Fat zero set.* If u vanishes on a set of F's interior in B_R(z) of measure ≥ c(d)R^d, Poincaré gives ‖∇u‖_{B_R(z)} ≤ C(d)RΦ(B_R(z))^{1/2}, so g_R ≤ C(d)R^{1−d/2}Φ(B_R(z))^{1/2} = C(d)R^{−1}Φ(B_R(z))^{1/2}.
- *Result.* With a = α and the fat zero set, for z′ ∈ B_{R/4}(z) and ρ₀ ≤ s ≤ R/8,

  abs(∇u(z′)) ≤ C(d)ρ₀²R^{−α/2}𝓔^{1/2} and osc_{B_s(z′)}u ≤ C(d)ρ₀²(s/R)^{α/2}𝓔^{1/2} (d = 4).

  Without the fat zero set, the terms ρ₀²g_R and ρ₀²s·g_R remain.
- *The case a = 2.* The dyadic sum of s^{−1+a/2} = 1 is ≤ C(d)(1 + log(R/s)), so the same steps give osc_{B_s(z′)}u ≤ C(d)ρ₀²s(M^{1/2}(1 + log(R/s)) + g_R).

## 6. The Coarse Data (Derived, Given Lemma B)

- Take one L-block Y with mean 1, the other means 0, and μ_Y = 0 on F.
- A bump competitor E_Y gives ‖∇²E_Y‖ ≤ C(d)L^{d/2−2}. Lemma A with w := e^{κ₀ρ_Y/L}, ρ_Y the distance to Y smoothed at the scale L, and (1′) of §4 give ‖w∇²μ_Y‖ ≤ C(d)L^{d/2−2}. So at every z, Φ(B_{L/4}(z)) and E_w are ≤ C(d)L^{d−4}e^{−2κ₀dist(z, Y)/L}.
- A bump test (ψ_B in B, Σψ_B = 1, abs(∇^kψ_B) ≤ C(d)L^{−d−k}) gives κ_B = a(μ_Y, ψ_B) = ⟨Mμ_Y, Mψ_B⟩, and abs(Mψ_B(x)) ≤ C(d)n^{−d/2}L^{−d−2}e^{−δ dist(y_x, B)/2} by Lemma M. So abs(κ_B) ≤ C(d)L^{−2−d/2}(‖∇²μ_Y‖_{B̃} + e^{−δL/8}w(B)^{−1}‖w∇²μ_Y‖), B̃ the L-neighbourhood of B, and R^{d+4}S ≤ C(d)(R/L)^{d+4}L^{d−4}e^{−2κ₀dist(z, Y)/L}. Hence 𝓔 ≤ C(d)L^{d−4}e^{−2κ₀dist(z, Y)/L} in §5's oscillation.
- Let s := dist(y, F) and d = 4. For s ≤ C(d)log L, take z ∈ F with abs(y − z) = s; F has a fat interior in B_{L/4}(z) (§5 (1)), and §5's oscillation with R = L/4 gives abs(∇μ_Y(y)) ≤ C(d)(log L)²L^{−α/2}e^{−κ₀dist(y, Y)/L}.
- For s > C(d)log L, let s′ := min(s, L/4). §5's oscillation gives osc_{B_{s′/2}(y)}μ_Y ≤ C(d)(log L)²(s′/L)^{α/2}e^{−κ₀dist(y, Y)/L}, and interior regularity at the scale s′, from translation invariance (derived as in #5.10.2.1), gives abs(∇μ_Y(y)) ≤ C(d)(log L)²s′^{−1}(s′/L)^{α/2}e^{−κ₀dist(y, Y)/L}. For s > L/4, s′ = L/4 accounts for the L-block multipliers, which keep μ_Y varying at the scale L.
- Weighted by n_Y = L^{j+1} with §3's factor L^{−j}, and summed over Y with Σ_Ye^{−κ₀dist(y, Y)/L} ≤ C(d), the coarse part of §3 is ≤ C(d)(log L)²L^{1−α/2}.

## 7. The Fine Data (Derived)

- On F, μ is rough at unit scale, with abs(μ) ≤ C(d)L^j𝒜. Write the response through the Green function G_S of the clamped, block-constrained problem. Its value at x ∈ C is Σ_{p∈F}P(x, p)μ(p), with abs(P(x, p)) ≤ C(d)Σ_{q∈C}e^{−δ abs(q − p)}abs(G_S(x, q)). Only the q within C(d)log L of F count, up to e^{−δ(d)·}-tails.
- So it suffices that Σ_{q: dist(q, F) ≤ C log L}abs(G_S(x, q)) ≤ C(d)(1 + log L)^qL^{1−η}, together with the same bound for its unit differences in x.
  - *The unit differences in x (derived).* Fix q with abs(x − q) = D, and let s′ := min(s_x, L/4, D/2). For q″ ∈ B_{D/2}(q), G_S(·, q″) solves the clamped homogeneous problem in B_{s′}(x), up to the L-block multipliers. Interior regularity at the scale s′, as in §6 (translation invariance with Lemma R, and the multipliers bullet below, which keeps the multipliers varying at the scale L), gives abs(∇_xG_S(x, q″)) ≤ C(d)s′^{−1}osc_{B_{s′}(x)}G_S(·, q″) + (multipliers).
  - The x-side bound below gives osc_{B_{s′}(x)}G_S(·, q″) ≤ C(d)(log L)³(s′/D)^{γ_x}. Since γ_x ≤ 1 and s′ ≥ 1, s′^{−1}(s′/D)^{γ_x} = s′^{γ_x−1}D^{−γ_x} ≤ D^{−γ_x}, in all three cases of s′.
  - ∇_xG_S(x, ·) is the response to a dipole at x, so it solves the same clamped problem near q, and the q-side exponents below apply to it with the sup on B_{D/2}(q) just bounded. So abs(∇_xG_S(x, q)) ≤ C(d)(log L)³D^{−β_c−γ_x}, the bound the count uses for G_S itself, up to logarithms.
- In d = 4, abs(G_S(x, ·)) ≤ C(d)log L everywhere (derived below). At the distance D ≤ L this is multiplied by (s_x/D)^{α/2}, by Lemma B at x (s_x := dist(x, F)).
- *G_S's size (derived; d = 4).*
  - G_S(x, x) = sup_{φ∈S₀, φ≠0}φ(x)²/a(φ, φ), and a(φ, φ) ≥ c₁‖Δ₀φ‖².
  - Split φ = φ_< + φ_> with the Fourier cutoff χ(Lθ), χ smooth, equal to 1 near 0 and supported in abs(θ) ≤ 1.
