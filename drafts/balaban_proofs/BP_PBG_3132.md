# Bałaban Proof: PBG (3.132), the Kernel Bound on (QGQ*)^{−1} and (QG₁Q*)^{−1}

A proof of PBG (3.132) on sequences with Ω₀ = T, which PBG p.422 l.15–19 states without proof ("We will not repeat these considerations here, let us write only bounds").

The tags {#BQ.n} are this file's own. PBG = CMP 99 (1985) 389–434, CMP96 = CMP 96 (1984) 223–250 (PBG's [4], PRT2 in BETA), CMP98 = PBG's [5]; pins are to Balaban\tex\PBG\parts\pNNN_corrected.tex and Balaban\tex\PRT2\parts\pNNN_corrected.tex, and CMP96 is cited by page and equation.

## Statement

- {#BQ.1} *Statement.* Let U be G-valued and satisfy PBG (3.35)–(3.36) for a sequence {Ω_j} with Ω₀ = T, and let G♯ be PBG's G (G^{−1} = Δ_π + DRD* + Q*aQ, (3.122)) or G₁ ((3.128)). There are M₂, a₂, O(1) and δ₁ > 0, depending on d, L and the constants of the inputs (I1)–(I8) (#BQ.13), such that for M ≥ M₂ and Mα₀ ≤ a₂, |(QG♯Q*)^{−1}(c,c′)| ≤ O(1)(L^jη)^{−2}(L^{j′}η)^{−d}e^{−δ₁d(c,c′)} for block bonds c, c′ of 𝔅 with c₋ ∈ Λ_j, c′₋ ∈ Λ_{j′}. This is (3.132).
  {#BQ.1-1} *Order.* The proof runs first for G♯ = G, then for G♯ = G₁. For G its inputs (I1)–(I2) come from Theorem 3.3 for G_C and BP_PBG_3130.md with X = Δ′_π, which uses no bound on (QGQ*)^{−1}. For G₁ they use BP_PBG_3130.md with X = Δ′_π + Δ^{(2)}_π and (3.137) (p.423 l.4–5), and (3.137) rests on (3.36) and on (3.133) for H (p.422 l.50), which PBG derives from (3.132) for G (p.422 l.21–22). So no input uses (3.132) for the operator under proof; (3.133) for H₁ follows afterwards (p.423 l.30–31).

## Two Lemmas on Sums

- {#BQ.5} *Lemma A.* For r > 0 and p ≥ 0 let c₀ := Σ_{z∈ℤ}e^{−½r|z|}. If ¼rRM ≥ 2d log c₀ + 1 + p log L, then sup_{y∈𝔅}Σ_{y′∈𝔅}L^{p|j−j′|}e^{−rd(y,y′)} ≤ 12L^pc₀^d. Proof: in CMP96 (2.58) (written there with r = αδ₀) the terms with given j′ and m carry e^{−½rmRM}c₀^{d(2m+1)}, and L^{p|j−j′|} ≤ L^pL^{pm} as m ≥ |j−j′| − 1; so the step (2.59) runs with c₀^{2d}L^p in place of c₀^{2d}, which the hypothesis allows. The same holds with R₀M₀ for RM on a sequence with constant R₀M₀ in (2.2).
- {#BQ.6} *Lemma S.* If |K(c,c′)| ≤ κL^{q(j−j′)}(L^{j′}η)^{−d}e^{−rd(c,c′)} for c₋ ∈ Λ_j, c′₋ ∈ Λ_{j′}, then ‖K‖_ℋ ≤ 12dκL^{d+|q|}c₀^d under Lemma A's hypothesis with p = d + |q|. Proof: the row sums Σ_{c′}μ(c′)|K(c,c′)| ≤ κΣL^{|q||j−j′|}e^{−rd} and the column sums Σ_cμ(c)|K(c,c′)| ≤ κΣ_cL^{(d+|q|)|j−j′|}e^{−rd} are bounded by Lemma A (a point carries d bonds), and Schur's test gives the norm.
  {#BQ.6-1} In particular, if |K(c,c′)| ≤ κ(L^jη)^s(L^{j′}η)^{−d}e^{−rd(c,c′)}, then W^{−s/4}KW^{−s/4} has the kernel (L^jη)^{−s/2}K(c,c′)(L^{j′}η)^{−s/2}, which is of this form with q = s/2, so ‖W^{−s/4}KW^{−s/4}‖ ≤ O(1)κ.

## Proof

- {#BQ.7} *Step 1 (decay of X♯).* Let e_{c′} be a unit vector of 𝔤 at c′ and 0 elsewhere, so (X♯e_{c′})(c) = μ(c′)X♯(c,c′). By (I3), J := Q*e_{c′} has |J| ≤ κ_Q, κ_Q the O(1) of (I3), and support in S_{c′} := B^{j′}(c′₋) ∪ B^{j′}(c′₊). As the blocks nest and each Ω_n is a union of cubes of size ML^nη, S_{c′} is covered by at most L^d + 1 cubes Δ(y″), and d(y″, c′₋) ≤ D = D(d, L) by (2.46), as an admissible contour of ℓ¹ length O(1)L^{j′+1}η joins them inside the regions of scales j′ − 1, j′, j′ + 1 (CMP96 (2.2)).
  {#BQ.7-1} By (I1), applied to each 1_{Δ(y″)}J, |(G♯J)(b)| ≤ (L^d + 1)κ_QB₀(L^{j_y}η)²max_{y″}e^{−δ₀d(y,y″)} for b ∈ Δ(y). By (I3), |(QG♯J)(c)| ≤ κ_Q max_{S_c}|G♯J|, and S_c is covered in the same way by cubes Δ(y) with j_y ≤ j + 1 and d(y, c₋) ≤ D. As d(y, y″) ≥ d(c, c′) − 2D (I8), |X♯(c,c′)| = μ(c′)^{−1}|(QG♯J)(c)| ≤ C_X(L^jη)²(L^{j′}η)^{−d}e^{−δ₀d(c,c′)}, C_X := (L^d + 1)κ_Q²L²e^{2δ₀D}B₀, as CMP96 (2.142) at U = 1. The same with (I2) gives |(X♯ − X_C)(c,c′)| ≤ O(1)Mα₀(L^jη)²(L^{j′}η)^{−d}e^{−½δ₀d(c,c′)}.
- {#BQ.8} *Step 2 (local sequences).* For □ ∈ 𝒟_j let □^{(n)}, n < j, be the cubes of PBG p.408 l.30–32 (centred at □'s centre, with dist((□^{(n)})^c, □^{(n+1)}) = 2R₀M₀L^nη), □^{(j)} := □̃⁴, □^{(n)} := □̃³ for n > j, and Ω_n(□) := □^{(n)} ∩ Ω_n. By (I6), □̃⁵ meets only B^{j′}(Λ_{j′}) ∪ B^{j′+1}(Λ_{j′+1}) with j ∈ {j′, j′+1}, so Ω_n(□) = ∅ for n ≥ j + 2, and inside □̃⁵ only the global scales j − 1, j, j + 1 occur.
