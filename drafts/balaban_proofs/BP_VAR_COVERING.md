# Bałaban Proof: Covering the Layers by VAR's Class Cubes

Bałaban proof: every point of a layer of Bałaban's determining sets lies in a cube of the class of VAR Theorem 1, and in one of the class its proof uses. Used by the LF note (WILSON_IT1_LARGE_FIELD_DEPTH_2026_10_27.md, #4.7-1-0). Tags continue the LF's numbering; a cited #4.x not in this file is in the LF or in another file of this folder. The class, a_j, and R₁M₁ = M′ are as in LF #4.7-1; the widths are in BP_LAYER_WIDTHS.md and BP_JOINS_BLOCK_SIZE.md (#4.24).

*The class of Theorem 1's statement.*
- {#4.7-1-1} For x in the layer j let δ(x) be its ℓ∞ distance from Ω_j^c in the units a_j. A class cube of side 2M′a_j is a union of big blocks, so a big block of the L^{−j}-lattice has side at most 2M′a_j. Among the cubes on the big-block grid that contain x there is one with x in its last big block towards any chosen side, in every coordinate.
  {#4.7-1-1-1} The cubes are half-open, so a cube □̃ reaching r from x lies within ℓ∞-distance < r of x. The reaches are compared in ℓ∞ with the widths of #4.24. Where such a width w is an ℓ¹ width (the joins, PRT2 p.223 l.16), it gives the ℓ∞ distance w/d, and every comparison of #4.7-1-2 to #4.7-1-5-2-1 holds with R′/d ≥ 12L (R′ ≥ 12dL, #4.22-0) in place of R′.
- {#4.7-1-2} *δ(x) ≥ 4M′: the index j.* Take M = M′ and □ ∋ x. Its faces are within 2M′ of x, so dist(□, Ω_j^c) ≥ 2M′ and □̃ ⊂ Ω_j. □̃ lies within 4M′ of x, and x ∉ Ω_{j+1}, while Ω_{j+2} lies at ≥ R′M′ in the units a_{j+1} (#4.24), so at ≥ LR′M′ > 4M′ in the units a_j, from Ω_{j+1}^c. So □̃ ⊂ Ω_j ∖ Ω_{j+2}, and □̃ ⊄ B^{j+1}(Λ_{j+1}) since x is in the layer j. No width of the layer j is used, so this holds also on the top layer of 𝐁₂ and of 𝐁_{1.70} (#4.14).
- {#4.7-1-3} *δ(x) < 4M′, with a layer j − 1 beyond Ω_j^c: the index j − 1.* Take M := 2LM′, a multiple of R₁M₁, and y ∈ Ω_j^c with |x − y|_∞ = δ(x); y lies in the layer j − 1, which is ≥ R′M′/L > 4M′ wide in the units a_j (R′ ≥ 12dL, #4.22-0). In the units a_{j−1} = a_j/L, □ has side 4LM′; place it with x in its last big block away from y (#4.7-1-1). Then □̃ reaches from x towards y at least 4LM′ − 2M′ + 2M′ = 4LM′ in the units a_{j−1}, that is 4M′ > δ(x) in the units a_j, so it contains y and meets B^{j−1}(Λ_{j−1}).
  {#4.7-1-3-1} □̃ lies within (4L + 4)M′ of x in the units a_{j−1}. The layer j − 1 is ≥ R′M′ ≥ ½LK_{M′}M′ > (4L + 4)M′ wide in its units (#4.24, K_{M′} ≥ 12d + 1), so □̃ ⊂ Ω_{j−1}. If the layer j is below the top, x lies at ≥ R′M′ − 4M′ > (4 + 4/L)M′ from Ω_{j+1} in the units a_j, so □̃ misses Ω_{j+1}. So □̃ ⊂ Ω_{j−1} ∖ Ω_{j+1}, and □ is a class cube of the index j − 1. This covers the rest of the top layer of 𝐁₂ and of 𝐁_{1.70}.

*The class of the proof.*
- {#4.7-1-5} *The proof's indexing.* VAR's proof takes the class one layer lower than Theorem 1's statement (#4.7-1) does (p.300 l.28, l.36–37): □ of side 2Ma_j, M a multiple of R₁M₁, meets Ω_j but not Ω_{j+1}, and □̃ ⊂ B^{j−1}(Λ_{j−1}) ∪ B^j(Λ_j) ⊂ Ω_{j−1}; (167) proves (9)–(10) on these cubes (#4.528). The covering holds for this class as well. For x in the layer j let δ⁺(x) be its ℓ∞ distance from Ω_{j+1} in the units a_j, with δ⁺(x) = ∞ in the top layer.
  {#4.7-1-5-1} *δ⁺(x) ≥ 4M′: the index j.* Take M = M′ and □ ∋ x (#4.7-1-1). □ meets Ω_j at x, and □̃ lies within 4M′ of x, so it misses Ω_{j+1}. Ω_{j−1}^c lies at ≥ R′M′/L ≥ 12dM′ > 4M′ from x in the units a_j (the layer j − 1's width, #4.24), and in the layer 0, with Ω_{−1} := Ω_0, δ(x) = ∞ on 𝐁 and 𝐁″_k (#4.7-1-4); the joins' bottom strips, that of 𝐁_{1.70} included, are #4.7-1-4-1–#4.7-1-4-2, and run B on T_{1.70} is #4.7-1-4-3–#4.7-1-4-3-2. So □̃ ⊂ Ω_{j−1} ∖ Ω_{j+1}.
  {#4.7-1-5-2} *δ⁺(x) < 4M′: the index j + 1.* Take M := 2M′ and y ∈ Ω_{j+1} with |x − y|_∞ = δ⁺(x) < 4M′/L ≤ 2M′ in the units a_{j+1}. Place □, of side 4M′a_{j+1}, with x in its last big block away from y (#4.7-1-1 at the index j + 1): it reaches ≥ 2M′ from x towards y, so y ∈ □ and □ meets Ω_{j+1}. □̃, of side 8M′a_{j+1}, lies within 8M′ of x in the units a_{j+1}.
    {#4.7-1-5-2-1} Ω_{j+2} lies at ≥ R′M′ > 8M′ from x (the layer j + 1's width, #4.24; if the layer j + 1 is the top one, Ω_{j+2} = ∅ and no width is needed), and Ω_j^c at ≥ (R′ − 4)M′/L ≥ (12d − 2)M′ ≥ 10M′ in the units a_{j+1}. So □̃ ⊂ Ω_j ∖ Ω_{j+2}, □ misses Ω_{j+2}, and □ is a cube of the proof's class of the index j + 1. M = 2M′ ≤ M(ε₁) by #4.7-3-1. Its bounds, 2B₃M′ε₁ times a_{j+1}^{−p} = L^{−p}a_j^{−p} (p ≥ 1, also for the Hölder term), are within those of the index j with M′, for L ≥ 2.
