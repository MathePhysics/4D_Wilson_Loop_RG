{#NG.0} Status: derived, not reviewed (2026-11-11). Owned by the BETA session; other sessions read it only.

{#NG.1} **Result.** A real function 𝔜 of a Wilson-loop function on five diagrams (three rectangles and two pairs, §1) vanishes for every Gaussian charge model and every limit of such models, with any normalisation of κ-form (§2). For Yang–Mills, 𝔜 of the continuum function does not depend on the normalisation and is the limit of 𝔜 of the unnormalised lattice expectations (§3).
{#NG.1-1} The free field's shape defect is positive (§4). The pair terms of 𝔜 are O(ḡ⁴) up to powers of log ḡ^{−2}, because the trace of π vanishes on the Lie algebra (§5). The shape term equals a stopping-scale expectation up to a super-polynomially small error (§6). That 𝔜(W) > 0 for small ḡ, which is non-Gaussianity in the sense of §2, is open: it follows from (O1) by #NG6.3.

{#NG.2} *Open.* (O1) The shape term at second order: liminf_K𝔶^{ℓ₀}_S(ε_K) ≥ cḡ² for a c > 0 and ḡ small (#NG6.1).
{#NG.2-1} Missing: (O1a) liminf_KΣ_𝖱n(𝖱)Re 𝐄_{ℓ₀}[I_{K′}(𝖱; ℓ₀)] ≥ −o(ḡ²), which needs the expectation of the insertion sum to depend on the loop only through its lengths and corners, up to o(ḡ²), so that the weights of #NG1.3-1 cancel it; (O1b) liminf_KΣ_𝖱n(𝖱)Re 𝐄_{ℓ₀}[χ(Hol_𝖱(U_{K′}(V))) − 1] ≥ 2cḡ², which needs the second moments of the linearised fluxes under 𝐏_{ℓ₀} at separated rectangles: around each flat connection, those of the twisted free fields of §4 up to a relative o(1) (#NG6.2-2); Lemma F(b) gives the sign uniformly in the twists.
{#NG.2-2} What closes it: (O1a) and (O1b). Then #NG6.3 gives 𝔜(W) ≥ cḡ²/2 > 0 for ḡ small.

## 1 The Witness {#NGS1}

{#NG1.1} Fix q ∈ ℕ, a coordinate plane (μ, ν), t, s ∈ uL^{−q}ℕ with 3max(4t, s) < T_ph, and an irreducible unitary representation π of G with χ := n_π^{−1}tr π, n_π := dim π. Let 𝖨_a := o + [at, (a + 1)t]e_μ + [0, s]e_ν for a = 0, …, 3 and 𝖱_n := o + [0, nt]e_μ + [0, s]e_ν, as loops of bonds traversed counterclockwise in (μ, ν), each with χ, where o ∈ uL^{−q}ℤ⁴ has o₀ = uL^{−q}.
{#NG1.1-1} The five diagrams are 𝖱₁ = 𝖨₀, 𝖱₂, 𝖱₄ and the pairs 𝖯_k := {𝖨₀, 𝖨_k}, k = 2, 3, whose loops are vertex-disjoint at ℓ^∞-distance (k − 1)t ≥ t. All five lie in 𝔊^{gl}_q (#GL9.2): 3diam_ph = 3max(4t, s) < T_ph for 𝖱₄ and less for the others, and the x₀-coordinates lie in [uL^{−q}, uL^{−q} + max(4t, s)] ⊂ (0, T_ph/2), as uL^{−q} ≤ t < T_ph/12.
{#NG1.2} For a function W on the five diagrams with nonzero values, 𝔜(W) := log|W(𝖱₄)| + 8log|W(𝖱₁)| − 3log|W(𝖱₂)| − 2log|W(𝖯₂)| − log|W(𝖯₃)| = 𝔶_S(W) − 2𝔶_2(W) − 𝔶_3(W), with the shape term 𝔶_S(W) := log|W(𝖱₄)W(𝖱₁)²/W(𝖱₂)³| and the pair terms 𝔶_k(W) := log|W(𝖯_k)/W(𝖱₁)²|.
{#NG1.3} *Counts.* Put n(𝖱₄), n(𝖱₁), n(𝖱₂), n(𝖯₂), n(𝖯₃) := 1, 8, −3, −2, −1. Let |𝔇| be the number of loops of 𝔇 and N_v(𝔇) the total length of its segments of orientation v. Then N_{±μ}(𝖱_n) = nt and N_{±ν}(𝖱_n) = s, a pair adds the lengths of its loops, and every loop has exactly one corner of each type (+μ, +ν), (+ν, −μ), (−μ, −ν), (−ν, +μ).
{#NG1.3-1} So Σn(𝔇)|𝔇| = 1 + 8 − 3 − 4 − 2 = 0, Σn(𝔇)N_{±μ}(𝔇) = (4 + 8 − 6 − 4 − 2)t = 0 and Σn(𝔇)N_{±ν}(𝔇) = (1 + 8 − 3 − 4 − 2)s = 0, and each corner type occurs |𝔇| times, so its weighted count is 0. The same holds for the weights 1, 2, −3 on 𝖱₄, 𝖱₁, 𝖱₂ alone (4 + 2 − 6 = 0 and 1 + 2 − 3 = 0); on these three, n(𝖱) denotes these weights.

## 2 Gaussian Charge Models {#NGS2}

{#NG2.1} *Definition.* A Gaussian charge model is a triple (𝗀, 𝖷, κ): 𝗀 ∈ ℝ; 𝖷 = (𝖷₀, …, 𝖷₃) a real Gaussian vector of any mean with Cov(𝖷_a, 𝖷_b) = c^G_{|a−b|}; and κ a function on loops with values in ℂ∖{0} of κ-form, log|κ(C)| = Σ_vλ_vN_v(C) + Σ_{c∈𝒦(C)}ζ_{v_c,w_c} with real numbers λ_v, ζ_{v,w} not depending on C. Put 𝖷(𝖨_a) := 𝖷_a, 𝖷(𝖱_n) := Σ_{a<n}𝖷_a, κ(𝔇) := Π_{C∈𝔇}κ(C) and W(𝔇) := 𝔼[Π_{C∈𝔇}e^{i𝗀𝖷(C)}]/κ(𝔇).
{#NG2.1-1} *Examples.* 𝖷(C) := ∮_C𝖡 for a Gaussian random 1-form 𝖡 whose law is invariant under translation by te_μ: on a lattice containing the five diagrams, or on the continuum torus when the line integrals over the sides of the five diagrams are L² limits of Riemann sums (L² limits of jointly Gaussian variables are jointly Gaussian). 𝖷(𝖱_n) = Σ_{a<n}𝖷(𝖨_a) as the interior sides are traversed once in each direction, and the invariance gives Cov(𝖷_a, 𝖷_b) = Cov(𝖷₀, 𝖷_{b−a}) for a ≤ b. This covers the U(1) lattice free fields at every spacing and charge in any gauge, and fields with a mean.
{#NG2.2} *Proposition G.* 𝔜(W) = 0 for every Gaussian charge model. If W_m are Gaussian charge models, each with its own (𝗀_m, 𝖷_m, κ_m), and W_m(𝔇) → W(𝔇) ≠ 0 for the five diagrams, then 𝔜(W) = 0.
{#NG2.2-1} *Proof.* For a real Gaussian Z, |𝔼e^{iZ}| = e^{−Var Z/2}. So W(𝔇) ≠ 0 and log|W(𝔇)| = −(𝗀²/2)Var 𝖷(𝔇) − log|κ(𝔇)|, with 𝖷(𝔇) := Σ_{C∈𝔇}𝖷(C). Here Var 𝖷(𝖱₁) = c^G_0, Var 𝖷(𝖱₂) = 2c^G_0 + 2c^G_1, Var 𝖷(𝖱₄) = 4c^G_0 + 6c^G_1 + 4c^G_2 + 2c^G_3 and Var 𝖷(𝖯_k) = 2c^G_0 + 2c^G_k.
{#NG2.2-2} With the weights of #NG1.3 the coefficient of c^G_0 is 4 + 8 − 6 − 4 − 2 = 0, that of c^G_1 is 6 − 6, that of c^G_2 is 4 − 4, and that of c^G_3 is 2 − 2. log|κ(𝔇)| is linear in the N_v(𝔇) and in the corner counts, so #NG1.3-1 gives Σn(𝔇)log|κ(𝔇)| = 0. Hence 𝔜(W) = 0, and 𝔜(W) = lim_m𝔜(W_m) = 0 as log|·| is continuous on ℂ∖{0}.
{#NG2.3} In a Gaussian charge model 𝔶_S(W) = −𝗀²(2c^G_2 + c^G_3) and 𝔶_k(W) = −𝗀²c^G_k: the covariances of the separated rectangles that make the shape term also make the pair terms. So 𝔜(W) ≠ 0 excludes every representation of W on the five diagrams by Gaussian charge models or their limits. These models are abelian; a 𝔤-valued Gaussian field with path-ordered holonomies is not one of them.

## 3 Yang–Mills: The Normalisations Drop Out {#NGS3}

{#NG3.1} For K with K′ = K − j_q ≥ 1 and the torus conditions of #GL9.2-1, let N_ε(𝔇) := E_ε[Π_{C∈𝔇}W_χ(C)]. Then W_ren(𝔇; ε) = N_ε(𝔇)/κ_𝔇 with κ_𝔇 := Π_{C∈𝔇}κ_{C,χ} ≠ 0 (#NV.9, read for 𝔊^{gl}_q by #GL9.7; #GL9.4).
{#NG3.2} *Proposition K.* (i) If N_ε(𝔇) ≠ 0 for the five diagrams, then 𝔜(W_ren(·; ε)) = 𝔜(N_ε). (ii) Under #GL7.1's conditions for the five diagrams and for ḡ below #GL9.8's thresholds for them, W(𝔇) := lim_KW_ren(𝔇; ε_K) exists and is nonzero, N_{ε_K}(𝔇) ≠ 0 for K large, and 𝔜(W) = lim_K𝔜(N_{ε_K}).
{#NG3.2-1} *Proof of (i).* |κ_𝔇| = Π_{C∈𝔇}|κ_{C,χ}|, and |κ_{C,χ}| = Π_{k≤K′}exp Re(A^{li}_k(C) + A^{co}_k(C)) (#GL9.4, #GL9.5-3). A^{li}_k(C) is a sum over v of N_v^{(k−1)}(C), at k = 1 of the coarse count of the segments of orientation v, times a coefficient of (k, v); A^{co}_k(C) is a sum over 𝒦(C) of a coefficient of (k, v_c, w_c). The coefficients are numbers of the step, the same for every loop with the character χ (#GL9.4-1).
{#NG3.2-2} For the five diagrams N_v^{(k−1)} and the coarse counts are the N_v(·) of #NG1.3 divided by the length of a step-(k − 1) bond, or of a coarse bond uL^{−q}. So #NG1.3-1 gives Σn(𝔇)log|κ_𝔇| = 0, which is (i).
{#NG3.2-3} *Proof of (ii).* The five diagrams lie in 𝔊^{gl}_q (#NG1.1-1), so #GL6.6-1 at level q gives the limits and #GL9.8 gives W(𝔇) ≠ 0. As W_ren(𝔇; ε_K) → W(𝔇) ≠ 0, W_ren(𝔇; ε_K) and N_{ε_K}(𝔇) are nonzero for K large, and log|·| is continuous on ℂ∖{0}.
{#NG3.3} *The prescription.* A change of normalisation of κ-form, such as a shift of a mass m_v or of a corner constant (#GL5.6-3), or a factor c^{|𝔇|}, leaves 𝔜 unchanged by #NG1.3-1. So 𝔜(W) does not depend on the renormalisation prescription.

## 4 The Free Field's Shape Defect {#NGS4}

{#NG4.1} *Setting.* 𝕋_ε := (εℤ/𝖳ℤ)⁴ with 𝖭_ε := 𝖳/ε ∈ ℕ, a twist θ ∈ [0, 1)⁴, 𝕋*_{ε,θ} := (2π/𝖳)(ℤ⁴ + θ) mod 2π/ε with p = 0 removed if θ = 0, p̂_α := (2/ε)sin(εp_α/2) and p̂² := Σ_αp̂_α², which is positive on 𝕋*_{ε,θ}. The θ-free field is a centred Gaussian 1-form 𝖡 on the bonds of εℤ⁴ with 𝖡(x + 𝖳e_β) = e^{2πiθ_β}𝖡(x) and 𝔼[𝖡_α(x)conj 𝖡_β(y)] = δ_{αβ}𝖳^{−4}Σ_{p∈𝕋*_{ε,θ}}e^{ip·(x−y)}/p̂², real at θ = 0 (the free field) and complex otherwise; 𝖡_α(x) lives on the bond from x to x + εe_α.
{#NG4.1-0} On the plaquette at x, 𝖥(x) := ∂_μ𝖡_ν(x) − ∂_ν𝖡_μ(x) with ∂_αf(x) := ε^{−1}(f(x + εe_α) − f(x)).
{#NG4.1-1} In Fourier, 𝖡(x) = Σ_p𝖡̂(p)e^{ip·x} and 𝖥̂(p) = d_μ(p)𝖡̂_ν(p) − d_ν(p)𝖡̂_μ(p) with d_α(p) := (e^{iεp_α} − 1)/ε, which vanishes for 𝖡̂(p) = d(p)φ̂(p). So a covariance changed by a term ξ(p)d_α(p)conj d_β(p), as by another gauge, gives the same covariance of 𝖥. For a rectangle 𝖨 of plaquettes traversed counterclockwise in (μ, ν), 𝖷(𝖨) := ∮_𝖨𝖡 = ε²Σ_{x∈𝖨}𝖥(x) (discrete Stokes).
{#NG4.2} *Lemma F.* Let 𝖨 be a rectangle of plaquettes of width t and height s in the plane (μ, ν), and 𝖨′ := 𝖨 + de_μ with d ≥ t. (a) If θ = 0 and d ≤ 𝖳 − t, then 𝔼[𝖷(𝖨)𝖷(𝖨′)] ≤ −(st)²/𝖳⁴. (b) For every θ, if d + t ≤ 𝖳/3, s ≤ 𝖳/2 and ε ≤ 𝖳/4, then Re 𝔼[𝖷(𝖨)conj 𝖷(𝖨′)] ≤ −(st)²/(1200𝖳⁴).
{#NG4.2-0} For the rectangles of #NG1.1 on 𝕋_ε with t, s ∈ εℕ put c^θ_k := Re 𝔼[𝖷(𝖨₀)conj 𝖷(𝖨_k)], c^F_k := c^0_k and D^θ := −(2c^θ_2 + c^θ_3), D^F := D^0. If 4t ≤ 𝖳, then c^F_k ≤ −(st)²/𝖳⁴ for k = 1, 2, 3 and D^F ≥ 3(st)²/𝖳⁴, by (a). If 12t ≤ 𝖳, s ≤ 𝖳/2 and ε ≤ 𝖳/4, then D^θ ≥ (st)²/(400𝖳⁴) for every θ, by (b).
{#NG4.2-1} *Proof.* 𝔼[𝖡̂_μconj 𝖡̂_ν] = 0 for μ ≠ ν and |d_α|² = p̂_α², so 𝔼[𝖥(x)conj 𝖥(y)] = 𝖳^{−4}Σ_{p∈𝕋*_{ε,θ}}e^{ip·(x−y)}(p̂_μ² + p̂_ν²)/p̂², and (p̂_μ² + p̂_ν²)/p̂² = 1 − Σ_{α∉{μ,ν}}p̂_α²/p̂². For z ∈ εℤ⁴, Σ_{p∈(2π/𝖳)(ℤ⁴+θ) mod 2π/ε}e^{ip·z} = 𝖭_ε⁴Σ_{n∈ℤ⁴}e^{2πiθ·n}δ_{z,n𝖳}. Take lifts with 𝖨′ = 𝖨 + de_μ in εℤ⁴. For x ∈ 𝖨, y ∈ 𝖨′, 0 < y_μ − x_μ < d + t ≤ 𝖳, so x − y ∉ 𝖳ℤ⁴, and the first part contributes 0 if θ ≠ 0 and −𝖳^{−4} if θ = 0, where p = 0 is removed.
{#NG4.2-2} In the second part fix p_⊥ := (p_α)_{α≠μ} with Σ_{α∉{μ,ν}}p̂_α² > 0, so that 𝗆² := Σ_{α≠μ}p̂_α² > 0, and let ϑ > 0 with cosh ϑ = 1 + ε²𝗆²/2. {#NG4.2-2.1} For the right side, g(z) := (ε/(2sinh ϑ))e^{−ϑ|z|/ε} solves the equation with the source ε^{−1}δ_{z,0}: for z ≠ 0 by 2cosh ϑ = 2 + ε²𝗆², and at z = 0 as 2 − 2e^{−ϑ} + ε²𝗆² = 2sinh ϑ. {#NG4.2-3} For 0 ≤ z ≤ 𝖳 put a := ϑz/ε, N := ϑ𝖭_ε, q := e^{−N} and φ := 2πθ_μ. At θ = 0, 𝗁 > 0 gives (a).
{#NG4.2-5} For (b), |x_μ − y_μ| < d + t ≤ 𝖳/3, so every term of the sum has nonnegative real part by #NG4.2-3.1; keep one. ## 5 The Pair Terms Are of Fourth Order {#NGS5}

{#NG5.1} *Lemma C.* Let G be compact, connected and semisimple, ϖ: G → U(n) a unitary representation and χ_ϖ := n^{−1}tr ϖ. If h := ‖ϖ(U) − 1‖_op ≤ 2/n, then |χ_ϖ(U) − 1| ≤ π²h²/8 ≤ (5/4)h², π here being the number.
{#NG5.1-1} *Proof.* det∘ϖ is a continuous homomorphism G → U(1) whose differential tr∘ϖ_* vanishes on [𝔤, 𝔤] = 𝔤, so it is 1 near the identity, hence on the connected G. Let e^{iθ_j}, |θ_j| ≤ π, be the eigenvalues of ϖ(U). Then 2|sin(θ_j/2)| ≤ h, and |sin y| ≥ 2|y|/π for |y| ≤ π/2 gives |θ_j| ≤ πh/2, so |Σ_jθ_j| ≤ nπh/2 ≤ π.
