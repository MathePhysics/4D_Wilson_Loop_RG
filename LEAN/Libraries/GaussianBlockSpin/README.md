# GaussianBlockSpin

Exact Gaussian algebra of Bałaban's block-spin renormalisation transformations, stated for
arbitrary finite-dimensional real inner product spaces so that it serves all of Bałaban's papers.

## Conventions and how the source maps onto them

- Measures are the canonical volumes of the inner product spaces (Mathlib's
  `measureSpaceOfInnerProductSpace`). For `F = (Y → ℝ^N)` with the plain Euclidean norm this is the
  coordinate Lebesgue measure `∏ dψ(y)`, which is Bałaban's `dψ`.
- With plain Euclidean norms the kernel coefficient is Bałaban's `a (L^{k+1}ε)^{d-2}` and the
  block average satisfies `Q Q* = L^{-d}·id` (gauge transports `U(A(Γ))` are orthogonal). Then
  `γ = αβ/(β + L^{-d}α)` with `α = a(L^{k+1}ε)^{d-2}`, `β = a_k(L^kε)^{d-2}` is
  `a_{k+1}(L^{k+1}ε)^{d-2}` exactly when `a_{k+1} = a a_k/(aL^{-2} + a_k)`, I.(2.13).
- `EffectiveForm` uses the same plain norms: `α = a_k (L^kε)^{d-2}`, `H = ε^d(-Δ^{ε,N}_{A,Ω} + m²)`
  as a plain matrix, `G = ε^{-d} G_k^ε` (the lattice adjoint is `Q_k^* = L^{kd} Qᵀ`). Then the
  exponent is exactly Bałaban's `⟨ψ, Δ^{(k)}ψ⟩` of I.(2.21) and `Z` is his `Z_k^ε` for the
  coordinate measures. (Using lattice inner products instead would keep the form but change `Z`
  by a Jacobian.)
- `blockKernel` is meaningful for `a > 0` only; it takes `ha : 0 < a` as a gate argument (no value for `a ≤ 0`).
- The lattice-specific facts (that Bałaban's `Q_k(A)` composes, `Q_{k+1}(A) = Q(A) Q_k(A)`, and
  satisfies `Q Q* = L^{-d}·id`) belong to the project layer (graph node `L.averaging-composition`).
- `[2]` in module headers and in the table is Part I's reference [2]: Benfatto, Cassandro, Gallavotti, Nicolò,
  Olivieri, Presutti, Scacciatelli, CMP 59, 143-166 (1978).
